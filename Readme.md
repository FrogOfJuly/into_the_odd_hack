# Premise

I wanted to have a Odd-like game with a resource that makes it possible for players to choose how to impact given roles. That gave rise to `Focus` and `Stress` system.


I wanted to have damage be more than just a number and make long-term impact on characters. That found it's form in `Injuries` with damage bounds and `Quirks`.


I wanted to have combat system be dice-goblin-friendly, thus gambits from `Mythic Bastionland`, spellweaving and witchcraft. 


I wanted to have no classes, but rather pick your meal character creation, which I decided to implement with `Feats`.
